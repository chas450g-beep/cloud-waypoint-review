SEE PREPARATION IN ACTION

One event. Three teams. A prepared handoff.

An unusual sign-in touches a mission application. Follow the handoffs to see what each team needs and what Foundations + application dependency mapping (ADM) helps prepare.

Fictional tabletop · Open a step to explore the people, process, technology and documents.

    Detect the signal

    An unusual sign-in. Unexpected traffic.

    Process
    In this fictional rehearsal, a cloud security service flags suspicious credentials touching a mission application. The cloud provider’s detection capability starts the story.
    Documents · operating team
    The operating team records the alert and its source. Cloud-provider detection is outside the Foundations + ADM preparation contribution.

    Start with a concrete event so everyone can follow the same handoffs.

  2. 02

    Understand the impact

    Which application? What depends on it?

    Boundary + application dependency baselineExplore this handoff +
    People
    Mission owner + cyber team
    Technology
    Application map + current telemetry
    Process
    The mission owner and cyber team use the recorded boundary and application relationships to focus the investigation. Operators confirm what is affected using current telemetry.
    Documents · Foundations + ADM
    Foundations defines the shared environment. Application dependency mapping (ADM) records observed relationships for owners to validate.

    The same application picture helps shape migration groups and focus the first moves.

  3. 03

    Reach the right team

    A named destination for the finding.

    Notification path + telemetry handoffExplore this handoff +
    People
    Cloud foundation team + cyber team
    Technology
    Monitoring feeds + case management
    Process
    The monitoring team routes the finding and context to its aligned Cybersecurity Service Provider (CSSP). The receiving service must be agreed and in place.
    Documents · Foundations + ADM
    Foundations records severity categories, notification responsibilities and the information each handoff needs.

    Teams can resolve gaps in ownership before the handoff is needed.

  4. 04

    Coordinate the response

    An agreed owner for the next action.

    Response responsibilities + rehearsal planExplore this handoff +
    People
    Cyber team + mission owner’s operators
    Technology
    Access controls + response tools
    Process
    The cyber team coordinates containment with the mission owner’s operators and cloud foundation team: who directs it, who performs it, and how the action is recorded.
    Documents · Foundations + ADM
    The operating model records the responsibility split, handoff approach and response rehearsal approach.

    A written plan becomes a shared conversation about people, decisions and actions.

  5. 05

    Confirm the recovery

    Check the fix. Preserve the result.

    Closure criteria + corrective-action ownershipExplore this handoff +
    People
    Cloud foundation team + cyber team
    Technology
    Service checks + security telemetry
    Process
    In an implemented environment, the responsible teams test the fix and record their results. In this tabletop, they identify what evidence that check would need.
    Documents · Foundations + ADM
    Foundations prepares the verification criteria and corrective-action record, with owners and milestones.

    Reviewers can distinguish planned work, observed results and remaining gaps.

  6. 06

    Assemble the working package

    Documents, owners and evidence in one place.

    Draft RMF package + operating handoffExplore this handoff +
    People
    Mission owner + security manager
    Technology
    Document and evidence register
    Process
    The system owner carries the draft security documents, responsibilities, evidence pointers and open actions into the Risk Management Framework (RMF) assessment and authorization process.
    Documents · Foundations + ADM
    Cloud Waypoint gives that package a head start: a draft security plan, control responsibilities, operating documents and corrective actions, informed by the current-state picture and transformation plan.

    The mission chooses how to carry the work forward: internally, with a delivery partner, or through a suitable platform.
